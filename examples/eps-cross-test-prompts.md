# Cross test prompts

Four short prompts used by the two `eps-cross-*` example workflows. Copy this
file into your EPSNodes library folder (the one configured in Settings →
EPSNodes) so the Prompt Notebook node can find it by name.

## Neon City

a neon-lit city street at night, rain-slick pavement, reflections

## Golden Hour

warm golden hour sunlight, long soft shadows, hazy air

## Ink Sketch

black ink sketch, bold confident linework, white background

## Pastel Studio

soft pastel studio portrait lighting, muted colors, clean backdrop
